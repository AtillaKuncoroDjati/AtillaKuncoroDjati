## About me

I'm **Atilla Kuncoro Djati**, a Computer Science graduate from **Universitas Mercu Buana**. I work on web applications, interface design, Windows desktop tools, and Python data analysis.

During my UI/UX internship at **PT. Meissa Berkah Teknologi**, I developed user flows, wireframes, and prototypes, then evaluated usability with users. My projects bring that attention to navigation and workflows into application development.
