## About me

Hi, I'm **Atilla Kuncoro Djati**, a Computer Science graduate from **Universitas Mercu Buana**, based in Jakarta, Indonesia.

I enjoy turning ideas into usable websites, thoughtful interfaces, and practical tools. My work spans Laravel applications, React interfaces, Windows desktop software, and Python data projects.

- **Build:** applications with clear workflows and useful features.
- **Design:** user flows, wireframes, prototypes, and accessible interfaces.
- **Explore:** data, automation, and new ways to solve everyday problems.
- **Experience:** UI/UX Designer intern at PT. Meissa Berkah Teknologi.
